    Building your first Discord app Documentation Discord Developer Portal translated

    网址：https://discord.com/developers/docs/quick-start/getting-started 时间：2025-09-10T22:11:58 标签：

    Discord应用允许您使用一系列API和交互功能来自定义和扩展Discord。本指南将引导您使用JavaScript构建第一个Discord应用，最终您将拥有一个能使用斜杠命令、发送消息并响应组件交互的应用。

    如果您有兴趣在iframe中构建游戏或社交体验，可以遵循构建活动的教程

    我们将构建一个让用户玩剪刀石头布（有7种选择而非3种）的Discord应用。本指南以初学者为重点，但假定您对JavaScript有基本了解。

    本指南使用的资源

    我们将使用的工具和技术概述

    步骤0：项目设置

    开始之前，您需要设置本地环境并从示例应用仓库获取项目代码。

    我们将在本地开发应用，并借助ngrok的帮助，但您可以使用偏好的开发环境。

    如果尚未安装NodeJS，请先安装。

    安装NodeJS后，打开命令行并克隆项目代码：

    git clone https://github.com/discord/discord-example-app.git

    然后导航到目录并安装项目依赖：

    # 导航到目录
cd discord-example-app
　# 安装依赖
npm install

    本教程使用的示例应用的项目结构概述

    完成这些后，在您选择的代码编辑器中打开新项目，我们将继续设置您的Discord应用。

    步骤1：创建应用

    首先，如果您还没有应用，需要在开发者门户中创建一个：

    创建应用

    输入应用名称，然后按创建。

    创建应用后，您将进入应用设置的"基本信息"页面，可以在此更新应用的基本信息，如描述和图标。您还会看到应用ID和交互端点URL，我们稍后将在指南中使用。

    获取凭据

    我们需要为您的应用设置并获取一些敏感值，如令牌和ID。

    您的令牌用于授权API请求并携带应用权限，因此高度敏感。确保永不分享您的令牌或将其提交到任何版本控制中。

    回到项目文件夹，将.env.sample文件重命名为.env。我们将在此存储所有应用凭据。

    您需要从应用设置中获取三个值用于.env文件：

    • 在"基本信息"页面，复制应用ID的值。在.env中，用复制的ID替换<YOUR_APP_ID>。
    • 回到"基本信息"页面，复制公钥的值，该值用于确保HTTP请求来自Discord。在.env中，用复制的值替换<YOUR_PUBLIC_KEY>。
    • 在"机器人"页面的"令牌"下，点击"重置令牌"生成新的机器人令牌。在.env中，用新令牌替换<YOUR_BOT_TOKEN>。

    除非重新生成，否则您将无法再次查看令牌，因此请确保将其保存在安全的地方（如密码管理器）。

    现在您已获得所需凭据，让我们配置您的机器人用户和安装设置。

    配置机器人

    新创建的应用默认启用机器人用户。机器人用户允许您的应用在安装到服务器时与其他服务器成员类似地出现和行为。

    在应用设置的左侧边栏中，有一个"机器人"页面（我们从中获取了令牌）。在此页面，您还可以配置设置，如特权意图或是否允许其他用户安装。

    标准权限与特权权限介绍

    目前我们不需要在这里配置任何额外设置，但根据您的应用使用场景，将来可能需要。让我们继续为应用安装做好准备。

    选择安装上下文

    现在我们将选择您的应用可以在Discord中安装的位置，这取决于您的应用支持的安装上下文。

    什么是安装上下文？

    应用可安装位置的概述

    点击左侧边栏中的"安装"，然后在"安装上下文"下确保同时选中"用户安装"和"服务器安装"。

    某些应用可能只希望支持一种安装上下文——例如，审核应用可能仅支持服务器上下文。但默认情况下，我们建议同时支持两种安装上下文。有关支持用户安装应用的详细信息，您可以阅读用户可安装应用教程。

    设置安装链接

    安装链接为用户提供了一种在Discord中安装应用的简便方式。我们将设置默认的Discord提供链接，但您可以在应用文档中阅读更多关于不同类型安装链接的信息。

    在安装页面上，转到"安装链接"部分，如果尚未选择，请选择"Discord提供链接"。

    当选择Discord提供链接时，将出现一个新的"默认安装设置"部分，我们接下来将进行配置。

    添加权限范围和机器人权限

    应用需要获得安装用户的批准才能在Discord中执行操作（如创建斜杠命令或获取服务器成员列表）。让我们在安装应用之前添加权限范围和权限。

    什么是权限范围和权限？

    权限范围和机器人权限介绍

    在安装页面的"默认安装设置"部分：

    • 对于用户安装，添加applications.commands权限范围
    • 对于服务器安装，添加applications.commands权限范围和bot权限范围。当您选择bot时，将出现一个新的"权限"菜单来选择机器人用户的权限。选择您的应用可能需要的任何权限——目前，我只选择发送消息权限。

    查看所有OAuth2权限范围的列表，或在文档中阅读更多关于权限的信息。

    安装您的应用

    在开发应用时，您应该在您的用户帐户上（对于用户可安装应用）和其他人未活跃使用的服务器中（对于服务器可安装应用）进行构建和测试。如果您还没有自己的服务器，可以免费创建一个。

    添加权限范围后，复制之前"安装链接"部分中的URL。

    由于我们的应用支持两种安装上下文，我们将把您的新应用安装到测试服务器和您的用户帐户中，以便我们可以在两种安装上下文中进行测试。

    安装到服务器

    要将应用安装到测试服务器，请从安装页面复制应用的默认安装链接。将链接粘贴到浏览器中并按回车键，然后在安装提示中选择"添加到服务器"。

    选择您的测试服务器，并按照安装提示操作。一旦您的应用添加到测试服务器，您应该会在成员列表中看到它出现。

    安装到用户帐户

    接下来，将应用安装到您的用户帐户。将相同的安装链接粘贴到浏览器中并按回车键。这次，在安装提示中选择"添加到我的应用"。

    按照安装提示将应用安装到您的用户帐户。安装完成后，您可以与其开启私聊。

    第二步：运行您的应用

    在您的应用程序已配置并安装到测试服务器和账户后，让我们来看一下代码。

    为了使开发更简单，该应用程序使用了discord-interactions，它提供了类型和辅助函数。如果您倾向于使用其他语言或库，请查阅社区资源文档。

    安装斜杠命令

    为了安装斜杠命令，该应用程序正在使用node-fetch。您可以在utils.js中的DiscordRequest()函数中看到安装的实现。

    该项目包含一个register脚本，您可以使用它来安装commands.js底部定义的ALL_COMMANDS中的命令。它通过调用HTTP API的PUT /applications/<APP_ID>/commands端点，将命令安装为全局命令。

    如果您想要自定义命令或添加其他命令，可以参考命令文档中的命令结构。

    在项目文件夹内的终端中，运行以下命令：

    ├── 示例      -> 简短、特定功能的示例应用程序
│   ├── app.js  -> 完整的app.js代码
│   ├── button.js
│   ├── command.js
│   ├── modal.js
│   ├── selectMenu.js
├── .env        -> 您的凭据和ID
├── app.js      -> 应用程序的主要入口点
├── commands.js -> 斜杠命令负载+辅助函数
├── game.js     -> 石头剪刀布游戏特定逻辑
├── utils.js    -> 实用函数和常量
├── package.json
├── README.md
└── .gitignore

    如果您返回到您的服务器，应该会看到斜杠命令出现。但如果您尝试运行它们，什么也不会发生，因为您的应用程序没有接收或处理来自Discord的任何请求。

    步骤3：处理交互性

    为了使您的应用程序能够接收斜杠命令和其他交互请求，Discord需要一个公共URL来发送它们。此URL可以在您的应用程序设置中配置为交互端点URL。

    设置公共端点

    要设置公共端点，我们将启动运行Express服务器的应用程序，然后使用ngrok公开我们的服务器。

    首先，转到您的项目文件夹并运行以下命令启动您的应用程序：

    npm run register

    应该有输出表明您的应用程序正在端口3000上运行。在幕后，我们的应用程序已准备好处理来自Discord的交互，包括验证安全请求标头和响应PING请求。我们在本教程中跳过了很多细节，但有关为交互准备应用程序的详细信息在交互概述文档中。

    默认情况下，服务器将监听发送到端口3000的请求，但如果您想更改端口，可以在.env文件中指定PORT变量。

    接下来，我们将启动ngrok隧道。如果您本地没有安装ngrok，可以按照ngrok下载页面上的说明进行安装。

    安装ngrok后，打开一个新的终端并创建一个公共端点，该端点将请求转发到您的Express服务器：

    npm run start

    您应该会看到连接打开，输出类似于以下内容：

    ngrok http 3000

    我们将使用转发URL作为可公开访问的URL，Discord将在下一步中发送交互请求。

    添加交互端点URL

    转到您的应用程序设置，在“一般信息”页面的“交互端点URL”下，粘贴您的新ngrok转发URL并附加/interactions。

    点击“保存更改”并确保您的端点已成功验证。

    如果您在验证端点时遇到问题，请确保ngrok和您的应用程序都在同一端口上运行，并且您已正确复制了ngrok URL。

    示例应用程序以两种方式自动处理验证：

    • 它使用 PUBLIC_KEY 和 discord-interactions 包，并通过一个包装函数（从 utils.js 导入）使其符合 Express 的 verify 接口。该函数会在每个传入应用的请求上运行。
    • 它响应传入的 PING 请求。

    您可以在 交互文档 中了解更多关于准备应用接收交互的信息。

    处理斜杠命令请求

    端点验证通过后，导航至项目的 app.js 文件，找到处理 /test 命令的代码块：

    隧道状态                 在线
版本                      2.0/2.0
Web 界面                 http://127.0.0.1:4040
转发                      https://1234-someurl.ngrok.io -> localhost:3000

    上述代码通过在其来源的频道、私信或群组私信中发送消息来响应交互。您可以在 文档中 查看所有可用的响应类型，例如使用模态框响应。

    前往您的服务器，确保应用的 /test 斜杠命令正常工作。触发时，应用应发送包含"hello world"及随机表情的消息。

    在下一节中，我们将添加一个使用斜杠命令选项、按钮和选择菜单来构建剪刀石头布游戏的附加命令。

    步骤4：添加消息组件

    /challenge 命令将用于启动我们的剪刀石头布风格游戏。当命令触发时，应用将向频道发送消息组件，引导用户完成游戏。

    在 commands.js 中名为 CHALLENGE_COMMAND 的 /challenge 命令包含一个 options 数组。在我们的应用中，这些选项是代表用户在玩剪刀石头布时可以选择的不同事物的对象，使用 game.js 中的 RPSChoices 键生成。

    您可以在 文档中 阅读更多关于命令选项及其结构的信息。
