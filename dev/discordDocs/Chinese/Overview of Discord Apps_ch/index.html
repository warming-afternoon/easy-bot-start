    Discord应用概览

    Discord应用为数百万用户定制、扩展和增强Discord体验。无论您是想要构建活动、自定义服务器还是集成游戏的开发者，应用都是将您的想法变为现实的容器。

    本页将回答以下问题：

    • 应用能做什么？
    • 应用安装在何处？
    • 应用可以使用哪些API？

    应用能做什么？

    当您探索文档并开始构建时，您会发现应用的全部可能性，但让我们先来看看在开发应用时可以构建和集成的一些功能。

    发送和管理消息

    消息是Discord的核心部分，对应用也是如此。应用可以通过几种方式发送消息——可以调用创建消息端点、创建和执行webhooks，或在响应交互时返回消息。

    如果应用具有适当权限，还可以管理消息，这在消息文档中有更详细的介绍。

    与用户互动

    应用可以使用交互为用户创造更具吸引力和直观的体验。发送消息时，应用可以在components字段中发送交互式组件，如按钮和选择菜单。应用还可以打开类似表单的模态窗口或启动活动以响应交互。

    构建嵌入式游戏和体验

    使用嵌入式应用SDK，应用可以创建活动，这些是在Discord中的跨平台互动游戏和社交体验。它们在Discord的iframe中运行，玩家们已经在那里聚集。

    自定义服务器

    通过正确的API端点和适当的权限，应用可以通过访问和自定义Discord核心的各种资源来定制使用和管理服务器的体验，包括用户、频道和自动审核等。探索资源文档类别，了解不同的Discord资源以及应用如何使用它们。

    更新用户元数据和状态

    应用可以通过几种方式使用来自派对游戏或应用的数据来更新Discord用户的元数据。应用还可以通过集成丰富状态来使用来自游戏或应用的可操作数据更新用户的个人资料。

    应用还可以使用角色连接元数据将第三方元数据（如统计数据或账户类型）与Discord用户关联，服务器管理员可以基于此设置角色。您可以在为链接角色配置元数据教程中了解更多信息。

    添加高级功能

    应用订阅允许应用直接在Discord内向用户和/或服务器定期收取高级功能费用。您可以在变现文档中阅读更多关于资格条件和为应用添加变现功能的信息。

    ...以及更多

    这份开发者文档包含各种功能的细节，值得深入探索。通过浏览更多文档或构建您自己的应用来发现更多可能性。

    应用安装在哪里？

    Discord应用可以在两种不同的环境中安装：

    1. 由具有管理服务器（MANAGE_GUILD）权限的用户安装到服务器（在API中称为公会 (guild)）。安装到服务器的应用只能在该服务器内以及与应用的机器人用户的私信中使用，并且对所有服务器成员可见。
    2. 安装到用户账户的应用。默认情况下，安装到用户的应用仅对该用户在所有服务器、私信和群组私信中可见。

    开发者可以在设置应用时限制应用支持的安装环境。

    有关安装环境的详细信息，请参阅应用资源文档。

    应用可以使用哪些API？

    有多种不同的API可供您根据应用的功能和想要访问的Discord功能进行选择。以下是Discord开发者平台上主要API的简要概述，但您可以在API参考中阅读更多关于API使用的详细信息。

    HTTP API

    HTTP API是一个REST API，允许您与核心Discord资源（如频道、服务器、用户和消息）进行交互和修改。

    使用HTTP API可以：

    • 检索资源信息
    • 创建、更新或删除资源

    在API参考中阅读有关使用HTTP API的详细信息。

    网关API

    网关API允许您通过WebSocket在安装应用的服务器中发生事件时接收事件数据。

    使用网关API可以：

    • 接收Discord中发生的事件

    在API参考中阅读有关使用网关API的详细信息。
